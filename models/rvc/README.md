# RVC Voice Models Directory

Este directorio aloja modelos de conversión de voz RVC v2 (Retrieval-based Voice Conversion) para síntesis de personajes anime (`.pth` e `.index`).

## Modelos soportados:
- **Nino Nakano (Español Latino - 500 Epochs)**
  - Carpeta: `models/rvc/Nino Nakano/`
  - Archivos: `Nino Nakano.pth`, `Nino Nakano.index`
  - Origen: [Google Drive (Ezarot)](https://drive.google.com/file/d/1xzNybpSlRlHuBznkZN1JNOS9W7MZQSnd/view?usp=sharing)
- **Miku Nakano (Español Latino - 500 Epochs)**
  - Carpeta: `models/rvc/Miku Nakano/`
  - Archivos: `Miku Nakano_500e_5000s.pth`, `Miku Nakano.index`
  - Origen: [Google Drive (Ezarot)](https://drive.google.com/file/d/1HJ6L35-ehufUQYkNfqq8WjQwwu3U_nb2/view?usp=sharing)

*Nota: Los archivos pesados `.pth` y `.index` están excluidos en `.gitignore` para mantener el repositorio liviano y transportable.*
